トラックの運転時間と連続運転

この章でわかること

  • 運転時間の「2日平均9時間」と「2週平均44時間」
  • 2日平均の判定方法(前日とも翌日とも超えたら違反)
  • 連続運転4時間と「運転の中断」の数え方
  • 計算問題の解き方の手順

1なぜ運転時間にも上限があるの?

拘束時間を守っていても、その大部分をハンドルを握って過ごせば、集中力は切れていきます。そこで改善基準告示は、拘束時間とは別に「運転そのもの」の長さにも上限をつけています。

2日平均1日あたり9時間以内
2週平均1週あたり44時間以内
連続運転4時間以内(途中で中断30分)

3つの物差しを全部守ります。「1日8時間」という運転時間の基準はありません(8時間は労働基準法の法定労働時間)。

22日平均9時間：前日とも、翌日とも

ある日(特定日)を決めて、「特定日と前日」の平均と「特定日と翌日」の平均の2つを出します。両方が9時間を超えたときだけ違反です。

前日との平均は超えているけれど、翌日との平均は9時間以内。片方がOKなので違反ではない。

前日との平均翌日との平均判定
9時間以内9時間以内OK
9時間超9時間以内OK
9時間以内9時間超OK
9時間超9時間超違反
計算のコツ平均を出す前に「合計が18時間を超えるか」を見ると速い。(前日＋特定日)と(特定日＋翌日)が、両方とも18時間超なら違反です。

32週平均44時間 ＝ 2週間で88時間

2週間の合計 88時間まで OK✗
044h88h

「2週間を平均して1週44時間」は、言いかえると2週間の合計が88時間以内。1週目が50時間でも、2週目が38時間なら合計88時間でOKです。

2週間の区切りは、特定の日を起算日として2週間ごとに区切って判断します。

バスとはちがうバスは「4週間を平均して1週40時間」。トラックは「2週間・44時間」。入れかえたひっかけに注意(→「バスの基準」)。

4連続運転4時間と「運転の中断」

連続運転時間とは、運転の中断をはさまずに運転し続けた時間です。4時間以内に、合計30分以上の中断を入れます。

連続運転4時間以内
中断合計30分以上。1回おおむね連続10分以上

数え方：中断が合計30分たまったらリセット

◯ の例

◯
1h2h1h
中断10分中断20分

運転1h → 中断10分 → 運転2h → 中断20分(ここで中断が合計30分) → 運転1h…。中断が30分たまるまでの運転は1＋2＝3時間で、4時間以内。

✕ の例

✕
2h1.5h1h → 4.5h
中断15分中断10分

中断は15＋10＝25分で、まだ30分に届いていない。その間の運転は2＋1.5＋1＝4.5時間で、4時間を超えて違反。

中断のこまかい決まり

  • 1回はおおむね連続10分以上。10分未満の中断を3回以上連続させない
  • SA・PAが満車で止められないなど、やむを得ないときは30分まで延長できる(最大4時間30分)
  • 運転の中断は、原則として休憩(荷役などの作業ではなく)

5例題で確かめよう

例題1

運転時間が、1日目9時間、2日目(特定日)10時間、3日目10時間だった。2日平均の基準に違反するか。

答えと解き方を見る
  1. 特定日と前日の平均：(9＋10)÷2＝9.5時間 → 9時間超
  2. 特定日と翌日の平均：(10＋10)÷2＝10時間 → 9時間超
  3. 両方とも超えているので違反。

例題2

次の運転は、連続運転時間の基準に違反するか。
運転1時間30分 → 中断10分 → 運転1時間 → 中断10分 → 運転1時間 → 中断10分 → 運転30分

答えと解き方を見る
  1. 中断を足していく：10分 → 20分 → 30分。3回目で合計30分に届く。
  2. それまでの運転：1.5＋1＋1＝3時間30分。4時間以内。
  3. 中断は1回10分以上で合計30分。よって違反ではない。最後の30分の運転は、ここから新しく数える。

例題3

2週間の運転時間が、1週目48時間、2週目42時間だった。2週平均の基準は守れているか。

答えと解き方を見る

合計90時間で、88時間を超える → 守れていない(平均すると1週45時間)。
