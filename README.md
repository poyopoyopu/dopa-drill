# 運行ドリル（運行管理者試験）

[grmchn/dopa-drill](https://github.com/grmchn/dopa-drill) のフォークです。元は算数の計算ドリルで、問題を1問解くたびに演出と音楽がどんどん盛り上がっていくゲームです。ここでは **問題だけを運行管理者試験の4択問題に差し替え**、演出・音・コンボ・スキルツリー・トロフィーなどのゲームの仕組みはそのまま使っています。ブラウザだけで動きます。

正解すると演出と音で祝ってくれます。問題を進めるほど画面と音が増えていき、最後はお祭りのような状態になります。まちがえても勢いは落ちず、ゲームオーバーもありません。正解すると解説が出ます（タップかEnterで次へ）。

## 特徴

- 運行管理者試験の4択問題 約820問、47スキル。貨物・旅客・労働時間（改善基準告示ほか）・車両法・道路交通法・実務上の知識の6分野
- スキルツリーは6ステージ。基本から入って、最後に全分野の「総まとめ」が解放されます
- 「じぶんレベル」モード：習熟に合わせて次のスキルを解放します（最初から全員ステージ1です）
- ステージ別モード、練習、復習（まちがえた問題）、スキルツリー画面
- 模擬試験モード（貨物・旅客）：本試験と同じ5分野・30問（8・4・5・6・7問）を通しで解き、合格基準（総得点18問以上、各分野1問以上、実務は2問以上）で合否を判定します。初回に正解した問題だけを得点にします。制限時間は本試験と同じ90分です。毎回の点数と分野別の得点を記録し、点数の推移を見られます。結果画面の「ここを練習」で、いちばん弱い分野のスキルをすぐ練習できます。
- 「ア・イ・ウの正誤の組合せ」や「誤っているものを選べ」など、本試験と同じ形式の問題もあります
- 全問正解で100点。初回正解率が80%以上なら、制限時間付きのエクストラで100点を超える得点を狙えます
- 音楽と効果音はすべてWeb Audio APIで合成しています（音声ファイルは使っていません）
- スマートフォンの縦画面とPCに対応。PCでは数字キー1〜4で入力できます
- 記録はすべて端末内（localStorage）に保存し、外部には送信しません

## 問題について

問題文・選択肢・解説は、条文（e-Gov法令検索）や公開資料を確認して書いた **オリジナルの学習用問題** です。過去問の転載ではありません。法令・告示は改正されるため、試験直前には必ず公式の最新資料で確認してください（各問に出典を付けています）。

問題は `app/js/bank_*.js` にあります。1問は次の形式です（正解を先頭に書くと、表示のときに並びがシャッフルされます）。

```js
{ q: '問題文', c: ['正解', '誤り1', '誤り2', '誤り3'], e: '解説', s: '出典' }
```

「ア・イ・ウ」のように並びを固定したい問題は `fix: true` と、正解の位置 `a`（0始まり）を付けます。追加後は `node --test tests/*.test.mjs` で形式を確認できます。

## 遊び方（ローカル）

ビルドは不要です。`app/` を静的に配信するだけで動きます。

```bash
python3 -m http.server 8000 -d app
```

ブラウザで `http://localhost:8000/` を開いてください。ES Modulesを使っているため、`file://` で直接開くと動きません。

## テスト

Node.js 20以上で実行します。

```bash
node --test tests/*.test.mjs
```
