# drafts/ — 下書き置き場

作り手（もち）が新規の下書きを提出する場所。app/ の外なので、本番ドメインからは配信されない（2026-11-16 に管理側が実測済み）。

## 使い方

- 新規の下書きファイルは、このフォルダの直下に置く（ファイル名は従来どおり：bank_draft_*.js、skills_*_draft.js）
- app/ の中には下書きを新規に置かない（app/ 内は、どのページからも読み込まれていなくても、URL を直接指定すると取得できるため）
- 置いたら、otsu4-drill の PROGRESS.md の「管理側への報告・質問」欄に、提出したファイル名と内容を書く
- その先は管理側（ムーちゃん）が行う。作問の下書きは、ファイルはここに残したまま、検品（チャッピー）で「確認済み」になった問題を本番バンクへ取り込む（取り込みは、その都度オーナーが判断する）。コード・実装の原案は、内容を確認し、ブランチを切って app/ の正しい場所へ入れて、PR を出す（マージはオーナー）
- 取り込み後も、このフォルダのファイルは原典として残す（削除は管理側の判断）
- 既存の問題データの修正は、このフォルダの対象外。従来どおり対象ファイルを main へ直接 push する
